# Website upgrade assessment — 29 October 2026

Scope: product/UX review of live homepage, current routes, recent desktop/mobile exam checks, implemented taxonomy filters and documented outstanding work. Not a security, SEO or full performance audit. No implementation in this assessment.

## Findings and recommended order

1. Make entry exam-first. Live homepage primary action currently selects ITI Instructor2026 for everyone; offer Choose your exam, then prioritize saved exam/Continue practice for returning learners using existing checkpoints. Keep UDC/LDC/Assistant easy to find. Replace internal-looking “1 sections” cards with useful paper/question coverage.
2. Reduce mobile chrome. Recent390px live checks show navigation, account actions and exam-scope controls consuming a large upper portion of the screen. Use a compact sticky header and secondary menu; retain clear active exam. Preserve boxed paper cards and narrow gutters.
3. Improve content discovery and completeness. Existing GK→Science grouping works, but Chandrayaan-5 in LDC is still only Current Affairs. Extend approved secondary-topic review and coverage dashboards; do not keyword-auto-publish. Add visible coverage dates and precise labels. Homepage “every MPSC paper” overstates coverage currently documented as incomplete.
4. Verify exam schemes. Original source-derived marks, duration, negative marking and sections must be confirmed per paper/version before offering a full-paper simulation. Current practice defaults are properly disclosed but remain a preparation limitation. Keep partial eligible practice distinct from source-confirmed full paper.
5. Make existing revision tools a daily routine. Reuse DailyRevision, Mistakes, StudyDesk and checkpoints for Continue, short revision and weak-topic work. Show small-sample cautions and question coverage alongside accuracy; do not rebuild existing progress tools.
6. Measure speed and learner completion. Recent17 science HTTP checks median0.463s/max1.129s describe those requests only. Instrument real first-question loading, failures, practice starts/completions, resume and return rates; prioritize mobile/cold-route bottlenecks from evidence.
7. Align homepage/product status and access messaging. Homepage still calls community posting, challenges, leaderboard and materials planned/in progress while corresponding routes exist. Check actual live usability/permissions and align copy rather than declaring every route launched. Clearly show free/paid benefits and expiry/extension status; admin extension controls should reuse authorization/audit patterns.

Suggested sequence: first exam entry/mobile header and stale copy; second content classification coverage + source-confirmed schemes; third existing revision integration and performance/usage measurement. Use quality and completion measurements to decide further expansion. No unsupported SEO/security/readiness score or conversion prediction.

## Owner scope clarification — MPSC now, expansion later

The current public product is for Mizoram Public Service Commission (MPSC) preparation. “Choose your exam” means choosing an MPSC examination/recruitment such as UDC, LDC, Assistant Grade, MCS or an applicable Group B recruitment—not choosing among exam commissions or national exam platforms. Homepage, navigation, onboarding and roadmap priorities should reflect MPSC. Broader exam-system selection should not compete with the present learner journey. Retain reusable canonical questions, source identities, exam-specific presentation and schemes so other exam systems can be added later. Expansion is future scope, not current implementation work. This clarification does not authorize deleting bank records or changing existing access/scope rules.
